# Guia do usuário

## 1. Escolha a direção

No primeiro acesso, escolha o idioma que você já conhece. O aplicativo define o outro idioma como alvo.

Você pode mudar a direção nos Ajustes. O progresso de cada direção fica separado.

## 2. Siga a página Hoje

Uma sessão diária equilibrada tem quatro partes:

1. Revisar os cartões vencidos.
2. Aprender até 10 itens novos.
3. Ouvir uma situação.
4. Falar em voz alta por alguns minutos.

A meta de itens novos pode ser alterada nos Ajustes.

## 3. Aprenda itens novos

A página Aprender mostra um item por vez. Quando possível, ouça antes de mostrar o significado.

Selecione `Eu sei` quando conseguir ligar a forma em inglês ao significado. O item entra na repetição espaçada. Selecione `Depois` para receber o cartão novamente mais tarde.

No curso de inglês, as trilhas incluem o núcleo de conversação, verbos, adjetivos, substantivos e um módulo profissional opcional.

## 4. Revise

A tarefa muda automaticamente:

- idioma alvo para significado;
- idioma conhecido para idioma alvo;
- áudio para significado.

Selecione `De novo` quando não lembrar. Selecione `Acertei` quando lembrar. Os intervalos avançam por 1, 3, 7, 14 e 30 dias.

## 5. Use as situações

Leia cada diálogo uma vez, esconda as traduções e ouça novamente. Depois repita cada fala logo após o áudio. Marque a situação como ouvida ao terminar.

## 6. Use o tutor

A prática guiada funciona sem chave. Ela apresenta um diálogo existente para escuta e repetição.

O tutor de IA é opcional. Para usá-lo, informe nos Ajustes seu próprio endpoint de chat completions compatível com OpenAI, modelo e chave de API. O aplicativo não inclui chave do autor. A chave informada dura somente durante a sessão do navegador.

Escolha entre cinco modos: conversa, dramatização, revisão de vocabulário, explicação ou prática de correção. Também é possível selecionar linguagem neutra, casual ou educada e informar um cenário curto. O aplicativo monta as instruções do tutor automaticamente.

## 7. Proteja o progresso

Use `Exportar progresso` regularmente. O JSON baixado contém as duas direções, datas de revisão e contagens diárias. Use `Importar progresso` para restaurar os dados em outro navegador.

## 8. Instale o aplicativo

Quando hospedado por HTTPS, use a opção Instalar ou Adicionar à Tela de Início do navegador. O aplicativo e os áudios usados entram no cache offline aos poucos.
