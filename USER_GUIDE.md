# User Guide

## 1. Choose your direction

On first launch, choose the language you already know. The application immediately sets the other language as your target.

You can change direction later in Settings. Progress for the two directions is stored separately.

## 2. Follow the Today page

A balanced daily session has four parts:

1. Review due cards.
2. Learn up to 10 new items.
3. Listen to one situation.
4. Speak out loud for a few minutes.

You may change the new-item goal in Settings.

## 3. Learn new items

The Learn page shows one item at a time. Listen before revealing the meaning when possible.

Select `I know it` when you can connect the target form to its meaning. The item enters spaced repetition. Select `Later` if you want it to return after other cards.

Tracks include the conversational core, verbs, adjectives and nouns. The English course also includes an optional professional track.

## 4. Review

The review sequence changes automatically:

- target language to meaning;
- known language to target language;
- audio to meaning.

Select `Again` when recall failed. Select `Good` when recall was successful. Review intervals grow through 1, 3, 7, 14 and 30 days.

## 5. Use situations

Read each dialogue once, then hide translations and replay it. Finally, repeat each line immediately after the audio. Mark the scene as listened when you complete it.

## 6. Use the tutor

Guided practice works without a key. It presents an existing dialogue for listening and repetition.

The live AI tutor is optional. To use it, enter your own OpenAI-compatible chat completions endpoint, model and API key in Settings. The application includes no author key. The entered key lasts only for the browser session.

Choose one of five practice modes: conversation, role-play, vocabulary review, explanation or correction. You can also select a neutral, casual or polite language style and add a short role-play scenario. The application builds the tutor instructions automatically.

## 7. Keep your progress safe

Use `Export progress` regularly. The downloaded JSON file contains your two learning directions, review dates and daily counts. Use `Import progress` to restore it in another browser.

## 8. Install the application

When hosted over HTTPS, use the browser's Install or Add to Home Screen action. The course shell and used audio files become available offline as they enter the runtime cache.
